# Curso: Construindo Aplicações com Vue 3 e Test Driven Development (TDD) 🧪🚀

Este curso é totalmente focado na **prática**! Vamos construir uma aplicação real utilizando o framework **Vue 3**, explorando as principais funcionalidades modernas do ecossistema Vue e aplicando o **Desenvolvimento Orientado a Testes (TDD)** desde o início até a entrega final da aplicação.

---

## 🧠 O que você vai aprender

- ✅ Criar aplicações com **Vue 3**
- ✅ Utilizar **Composition API** e **Options API**
- ✅ Criar **rotas no lado do cliente** com `vue-router`
- ✅ Adicionar **internacionalização (i18n)** com `vue-i18n`
- ✅ Gerenciar **estado global** com `pinia`
- ✅ Aplicar **Test Driven Development (TDD)** em todo o projeto
- ✅ Escrever testes utilizando `vitest` e `@testing-library/vue`
- ✅ **Mockar dependências externas** nos testes
- ✅ Sentir na prática como o TDD melhora a **qualidade do código**, a **reutilização** e dá mais **confiança ao refatorar**
- ✅ Entender as diferenças entre **testes unitários** e **testes de integração**
- ✅ Aprender a evitar o acoplamento a detalhes de implementação nos testes

## 📚 Metodologia

O curso é dividido em seções práticas. A cada nova funcionalidade da aplicação, aplicamos o ciclo do TDD:

1. **Escrever o teste primeiro**  
2. **Fazer o código passar no teste**  
3. **Refatorar o código com segurança**

Cada novo requisito é desenvolvido com base no anterior, sem pular etapas. Assim, você verá como **projetar uma aplicação completa**, passo a passo, com confiança e qualidade.
